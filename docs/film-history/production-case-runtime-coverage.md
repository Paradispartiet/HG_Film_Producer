# Runtime production-case coverage

The historic static audit counts expansion definitions as film-specific briefs. Russian Ark and Atanarjuat exposed that a verified source dossier and historical profile did not guarantee an actual playable brief. This update keeps all previously registered brief resolvers ahead of a shared evidence-mapped bridge. The bridge requires an exact-ID verified record and exact-ID film history profile, and builds six mission targets from the film's own documented profile and source notes. Where no department evidence is recorded, the target explicitly asks for research instead of inventing a technique. Unknown IDs still use seed fallback. It creates no new canonical IDs or verification records, and does not modify existing mission IDs or registered brief contents.

Run `npm run audit:production-runtime` to obtain the measured counts and exact list of newly mapped films. It executes the real catalogue, brief, verification, profile and mission functions, validates 614 identities, checks registered brief equality and all six missions, and rejects unresolved or invalid cases. It runs inside the existing verify command, not an additional GitHub workflow. The mapped targets are reuse of existing editorial content, not newly independently reviewed film-specific game design. Actual counts are pending CI; do not infer them from the older static audit.

## First runtime findings and resolution

The first run of the actual runtime audit reported 614 catalogue IDs, 380 registered production briefs, 218 newly mapped briefs and 16 unresolved early films (598/614 playable). It also reported existing registered cases absent from the *base* historical profile map. Inspection found that the production bridge used the base getter alone, whereas the existing film-study UI searched 38 specialist batch registries before the base registry. The shared profile resolver now uses that exact previous UI order, and the production bridge uses the same history profile lookup. The runtime audit also checks that the displayed film study and mapped brief select the same exact-ID profile. No new historical profiles or verification records were authored; no history-choice donor order or existing production brief was intentionally changed. The second audit must establish actual coverage before claiming completion.
